# CyberNex - Cyborg-Themed Landing Page

A futuristic, cyberpunk-themed landing page developed for **Techfest - Task 1 (Web Development)**.

## 🚀 Live Demo
- **Live URL:** [https://pankaj24112005.github.io/cybernex-cyborg-landing-page/](https://pankaj24112005.github.io/cybernex-cyborg-landing-page/)

---

## ✨ Features
- **Cyberpunk / Cyborg HUD Design:** Neon accents, dynamic telemetry counters, and high-tech typography.
- **Interactive System Diagnostics:** Real-time modular stats, neural core status, and system monitors.
- **Embedded Terminal CLI:** Functional command-line interface simulation.
- **Web Audio FX:** Synthesized futuristic sound effects powered by the Web Audio API.
- **Fully Responsive:** Smooth layout across desktop, tablet, and mobile devices.

---

## 🛠️ Built With
- **HTML5**
- **Tailwind CSS** (via CDN)
- **JavaScript (Vanilla)**
- **Web Audio API**
